# Golf Performance Analytics
## Project Overview
Golf Performance Analytics is a full-stack application designed to help golfers track, analyze, and improve their performance through data-driven insighnts.

The application allows golfers to record and manage their rounds, track key performace metrics, and identify trends in their game over time.

The project aims to combine software engineering, statistical analysis, data visualization, and artificial intelligence into a unified golf performance platform.

### Current Implementation
- RESTful API built with FastAPI
- Golf round creation, retrieval, modification, and deletion
- Data validation using Pydantaic
- Basic scoring statistics
- Automated API integration testing using Pytest

### Planned Functionality
- Persistent data storage using SQLite
- Historical performance analysis
- Interactive statistics dashboards
- AI-powered personalized performance insights
